# G-ONE 교원성장플랫폼 · 프로토타입

「현장친화적 교원 성장 플랫폼 구축 방안」(교원 성장 플랫폼 TF, 2026. 10. 21.) 보고서의 서비스 구조도를 그대로 옮겨 만든 클릭형 프로토타입입니다.

- 바로 보기: https://shinnanchanguk.github.io/g-one-prototype/
- 사람·학교·수치는 모두 샘플입니다. 누른 기록(신청·좋아요·글쓰기 등)은 각자의 브라우저에만 저장되며, 오른쪽 위 사용자 메뉴에서 처음 상태로 되돌릴 수 있습니다.

## 화면 구성 (보고서 메뉴 번호)

| 메뉴 | 화면 |
|---|---|
| 초기화면 | 수업 공개 현황(지도) · 교육청/지원청 연수 신청 · 포트폴리오 · 학습방/공동체 통합 · 교육 자료 추천 · 고민 남기기 |
| 1. 성장 | 1.1 성장 설계(고민 입력 → 10개 영역 진단 → AI 성장 키워드 → 도움 찾기 → 새 성장 목표) · 1.2 성장 여정(포트폴리오 · 뱃지 앨범 · 성장 일기 · 활동 이력 · 전문가 인증) |
| 2. 배움 | 2.1 연수와 모듈(조건 필터 · 모듈 제작 · 연수 신청) · 2.2 교육자료(업로드 · 좋아요 · 활용 평가) · 2.3 학습방 |
| 3. 나눔 | 3.1 공개수업(달력형/지도형 · 참관 신청 · 공개하기) · 3.2 공동체(찾기 · 만들기 · 게시판 7종) · 3.3 성과나눔 |
| 4. 동행 | 4.1 고민 남기기 · 멘토 찾기(우수멘토 표시) · 4.2 멘토링 현황 |
| 5. 안내 | 소개 · 공지사항 · FAQ |

## 개발

```bash
npm install
npm run dev
npm run build
```

디자인은 Chroma 테마(Space Grotesk · JetBrains Mono · Wanted Sans, 모두 OFL, `public/fonts`)를 썼습니다. 경기도 시군 경계는 통계청 2013 경계(southkorea-maps)에서 `scripts/build-map.py` 로 만들었습니다.
